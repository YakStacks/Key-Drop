## Full description (4,000 characters max)

```
KeyDrop adds the one button Android never shipped: a floating "hide keyboard" button that
works with whatever keyboard you already use.

Gesture navigation removed the reliable "dismiss keyboard" arrow, and every keyboard handles
it differently. KeyDrop puts a small button back on screen — but only while a keyboard is
actually open — so you can drop the keyboard from anywhere without hunting for a gesture.

WHAT IT DOES

• Shows a compact floating button only while the on-screen keyboard is visible.
• Tap it to dismiss the keyboard. That is the whole feature.
• Drag it anywhere; it snaps to the nearest edge and remembers where you left it, including
  after you rotate the screen.
• Works with any keyboard — Gboard, Samsung Keyboard, SwiftKey, or anything else. KeyDrop
  does not replace your keyboard and does not care which one you use.
• Stays out of the way: the button never appears on the lock screen, and it disappears the
  moment the keyboard does.

PRIVATE BY DESIGN

• No internet permission. KeyDrop literally cannot send anything anywhere.
• No analytics, no advertising, no account, no cloud.
• KeyDrop saves only the button position and whether you accepted the setup disclosure.
  Both stay in private storage on your device.

ABOUT THE ACCESSIBILITY PERMISSION

KeyDrop uses Android's Accessibility Service, because that is the only way an app can know
that a keyboard window is open and can dismiss it from outside the current app.

Android grants that permission broadly, so here is exactly what KeyDrop does with it: it
checks whether a window of type "input method" exists, and it sends the standard Back action
when you tap the button. It does not read what you type, does not inspect the contents of the
screen, does not take screenshots, and does not collect or transmit any data. KeyDrop shows
this explanation inside the app and asks you to agree before it opens Accessibility Settings,
and you can turn the service off at any time in Android Settings.

KeyDrop is a general-purpose utility, not an assistive tool for users with disabilities.

GOOD TO KNOW

• Requires Android 7.0 or newer.
• A few manufacturers do not report the keyboard as a system window reliably, so the button
  may not appear on every device or in every app.
• The button uses Android's global Back action, which follows whatever the app in front does
  with Back.

```
